# AI-Powered MSME Business Advisory Platform

Smart India Hackathon 2026 Prototype

## Problem Statement

AI-driven MSME business advisory system providing:

- Business recommendations
- Scheme eligibility guidance
- Financial projections
- Market insights
- Geographic business discovery
- Village-level MSME visualization

## Datasets

1. Telangana Udyam MSME Dataset
2. District MSME Statistics Dataset
3. Telangana Village Boundary Dataset
4. Telangana Village Coordinates Dataset

## Technology Stack

### Current Prototype

- Python
- Pandas
- GeoPandas

### Planned Full System

- React
- FastAPI
- PostgreSQL
- Leaflet Maps
- Machine Learning Models

## Features

- MSME Business Suggestions
- Financial Viability Calculator
- Village-wise Opportunity Analysis
- Interactive Map Visualization
- Scheme Recommendation Engine
